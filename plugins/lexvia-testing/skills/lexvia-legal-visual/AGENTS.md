# Lexvia Legal Visual

Treat a standalone pasted Chinese or bilingual Australian legal article, social-media copy, headline with supporting notes, or policy update as a request to create the finished LEXVIA social-media image. Do this in the same turn; do not ask what the user wants to do with the pasted copy.

For that workflow, read and follow [SKILL.md](SKILL.md). Use the image-generation tool, inspect the result, and return the final image inline. Default to a premium 3:4 portrait composition when no format is given.

Do not apply this workflow when the user explicitly asks for legal analysis, fact-checking, copywriting, translation, or other text-only work.
